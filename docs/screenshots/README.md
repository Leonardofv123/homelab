# Screenshots

Prints dos serviços rodando, pra ilustrar o README e documentar o estado do lab.

Sugestão do que colocar aqui (e como nomear, pra ficar organizado):

- `proxmox-overview.png` — tela inicial do Proxmox com a VM e o container
- `pfsense-dashboard.png` — dashboard do pfSense
- `pfsense-firewall-rules.png` — regras de firewall
- `adguard-dashboard.png` — painel do AdGuard com os números de bloqueio
- `adguard-filters.png` — listas de bloqueio ativas
- `npm-proxy-hosts.png` — lista de proxy hosts no Nginx Proxy Manager
- `uptime-kuma.png` — monitores no Uptime Kuma
- `scrutiny-dashboard.png` — saúde do disco no Scrutiny
- `homepage.png` — painel central
- `topology.png` — a topologia (export do draw.io)

Antes de subir qualquer print, confere que não aparece:

- IP público
- token, chave de API ou senha
- QR code de 2FA

Os hostnames internos (`.home.<seu-dominio>`) podem ficar, são privados e não resolvem de fora.
